# Website UI Design

Produce websites that look designed by a human, not generated by a template.
This skill pairs a curated multi-style library with the taste methodology:
read the brief first, design with intent, then de-AI the result before delivery.

## When to use

- "设计一个网站 / landing page / 作品集 / 官网"
- "帮我做个有设计感的页面" or a request to restyle an existing web UI
- A Chinese traditional-color or 国风 brief

## Core principle

```
Brief → Design Read → pick style → build tokens → build layout
      → [MANDATORY] taste / anti-slop refinement → deliver
```

The taste pass is not optional. Deliver only after the Pre-Flight Check in
`references/anti-slop.md` passes.

## Workflow

### Phase 0 — Design Read (brief inference)

Before writing any code, infer the design direction from the user's brief:

- **Product / purpose**: landing, portfolio, SaaS, shop, editorial
- **Audience**: age, sophistication, device
- **Brand personality**: 3 adjectives (for example 稳重·专业·克制)
- **Constraints**: content volume, must-have sections, tech stack, dark/light, locale
- **Design direction**: recommend 1–2 styles from the library below

If the brief is thin, ask at most 3 sharp questions. Do not start coding on guesses.

### Phase 1 — Style selection

Pick ONE primary style. Recommend from Phase 0, and let the user override.
Full token specs live in `references/style-library.md`.

| Style | Vibe | Best for |
|-------|------|----------|
| 中国古典 (Chinese Classical) | 含蓄·文气·留白 | 文化/品牌/茶/器物/国风 |
| 新野兽派 (Neo-Brutalism) | 大胆·原始·高对比 | 创意/作品集/初创/年轻品牌 |
| 极简瑞士 (Minimalist Swiss) | 克制·网格·专业 | SaaS/编辑/产品官网 |
| 玻璃拟态 (Glassmorphism) | 通透·轻盈·现代 | App 落地页/仪表盘/科技 |
| 暗黑科技 (Dark Tech) | 酷感·发光·未来 | 开发者工具/AI/数据 |
| 复古孟菲斯 (Retro Memphis) | 玩味·几何·多彩 | 活动/潮牌/儿童/艺术 |
| 包豪斯 (Bauhaus) | 原色·几何·理性 | 设计机构/教育/展览 |
| 柔和有机 (Soft Organic) | 温暖·圆润·亲和 | 健康/母婴/生活方式 |

For 中国古典, load `references/chinese-colors.md`. The article 《你绝对没见过的中国传统色》
(公众号·AIGC设计便利店) presents 5 unique 双色搭配 across 8 page slots. Use the
sampled hexes. The printed hex on every card is wrong.

| Pairing | Warm (TOP) | Cool (BOTTOM) | Use when |
|---------|------------|---------------|----------|
| 豆黄 × 群青 | `#FFDF70` | `#153472` | 国潮活动、文化展 |
| 扶光 × 中国红 | `#EFC2A3` | `#DA0011` | 中式喜庆、女性品牌 |
| 丹红 × 深海绿 | `#FE5C1B` | `#1A3B32` | 茶饮、餐饮、潮牌东方 |
| 水蓝 × 鹤蓝 | `#9ED4F0` | `#144975` | 科技文化、博物馆 |
| 淡粉 × 金红 | `#EBD2D6` | `#E45600` | 茶器、手作、轻奢东方 |

群青 `#153472` and 群青（浅）`#4C8DAE` are different colors. Do not swap them.

### Phase 2 — Build the design-token system

Define CSS custom properties before any component:

- `--bg`, `--surface`, `--text`, `--text-muted`, `--primary`, `--on-primary`, `--accent`, `--border`
- `--radius`, a `--space` scale, `--shadow`, `--font-display`, `--font-body`
- Motion: `--motion` duration and easing. Keep it restrained unless the brief asks otherwise.

Copy `assets/starter.html`. Inject tokens. Write real, specific copy. Never lorem.
Button labels use `--on-primary`, not `--bg`.

Before layout polish, check every text/background pair:

```bash
python3 scripts/contrast.py #161823 #FE5C1B
```

Body text needs 4.5:1. Large text (24px, or bold and at least 18.67px) needs 3:1.
A normal button label is body text. If python3 is missing, calculate the ratios anyway.

### Phase 3 — Build the layout

Apply the chosen style's component language from `references/style-library.md`:

- Asymmetric or intentional grids. Not a default row of three equal cards.
- Real vertical rhythm. Bottom-align CTAs inside a card group.
- One deliberate focal element per viewport.
- Delete the Chinese pair-card section unless the style is 中国古典.

### Phase 4 — TASTE / anti-slop refinement (MANDATORY)

Run `references/anti-slop.md` as a checklist:

1. Remove every forbidden pattern (purple mesh gradients, fake product chrome, scroll cues, em dashes in page copy, decorative confetti).
2. Tune VARIANCE / MOTION / DENSITY to levels that fit the brief.
3. Pass the Pre-Flight Check. Every item must honestly pass.
4. If any item fails, fix it and re-check. Do not deliver a failing page.

Scroll motion, when used at all, is CSS `animation-timeline` (with a static
fallback). Do not add a scroll event listener or a third-party scroll library.
Honor `prefers-reduced-motion`.

Only after Phase 4 passes, present the result.

## Example

Brief: "给一家年轻茶饮品牌做官网，要东方，不要模板感。"

- Design Read: 零售落地页，年轻但要留白，必须有菜单和门店。
- Style: 中国古典, pairing 丹红 × 深海绿 (`references/chinese-colors.md` §2.3).
- Layout: asymmetric hero, two zig-zag features, no three equal cards. Ink `#161823` on 丹红, paper `#FFF7EE` only on the 深海绿 band.
- Gate: `python3 scripts/contrast.py #161823 #FE5C1B` and the Pre-Flight Check.

A longer walkthrough is in `references/example.md`.

## Edge cases

- The brief is not 国风: delete the pair-card section. Do not force Chinese colors onto it.
- Contrast fails: change the text token or the role. Do not edit the five sampled pair hexes.
- The brand actually is purple: the brand purple may stay. A generic purple mesh blob still may not.
- No python3: still check contrast. Do not skip the Pre-Flight Check.

## Deliverables

- A self-contained `index.html` (tokens, layout, and content) the user can open
- A short rationale: which style, why, and which de-AI fixes were applied
- The live file, shown to the user
